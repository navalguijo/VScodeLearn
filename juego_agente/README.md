# Juego básico con pygame

Este proyecto contiene un juego sencillo donde puedes mover un cuadrado azul usando las flechas del teclado.

## Requisitos
- Python 3.x
- uv (gestor de dependencias)

## Instalación

1. Instala las dependencias usando uv:

   ```sh
   uv pip install --upgrade pip
   uv pip install -r pyproject.toml
   ```

2. Ejecuta el juego:

   ```sh
   python main.py
   ```

## Contenido
- `main.py`: Código fuente del juego.
- `pyproject.toml`: Configuración del proyecto y dependencias.

## Controles
- Flechas del teclado para mover el cuadrado.

¡Disfruta el juego!
