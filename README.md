# MiJuego01

Este repositorio contiene el proyecto **MiJuego01**, un juego sencillo desarrollado en Python.

## Descripción
MiJuego01 es un proyecto educativo para aprender programación en Python. El juego está diseñado para ser fácil de entender y modificar.

## Estructura del proyecto
- `MiJuego01.py`: Código fuente principal del juego.
- `README.md`: Documentación del proyecto.

## Requisitos
- Python 3.8 o superior

## Instalación y ejecución
1. Clona el repositorio:
	```
	git clone <url-del-repositorio>
	```
2. Navega a la carpeta del proyecto:
	```
	cd VScodeLearn
	```
3. Ejecuta el juego:
	```
	python MiJuego01.py
	```
